# Reliability of lattice gauge theories: artifact/history sidecar

Research date: 2026-08-27 (session-local date). Primary-source web inspection only; no pilots, agents, simulation runs, or Dataverse 3RXD5F inspection. Main session reports `Codes.rar` and 13 tabular files there; their contents/fitness are not independently verified here.

## Decision first: four distinct capability gaps

Recommended shortlist after the SU(3) discovery: **measurement inference; microscopic-ramp transfer; open-bath validation; SU(3) LSH protection transfer**. These are proposed software tasks, not claims that four executable author packages are available. Keep coefficient certification as a bounded component/fallback, not a fourth simulator.

1. **Measurement/gauge-sector inference, not full-state tomography.** Reuse the main session's measurement tables and analysis routines, conditional on their schemas. Build the measurement-to-local-constraint map and propagate calibration/finite-sample uncertainty; distinguish identifiable sector populations from unavailable coherences. Reference checks: original paper Eqs. (2), (4) and supplemental observable definitions [R0]; decoherence paper Eqs. (5–6) gives sector-projector observables [N0]. Proposed acceptance: known physical/defect configurations give the correct projectors, probabilities normalize, and reconstructed averages match author tables. Aggregate means alone must not be advertised as complete tomography.
2. **Microscopic-ramp-to-effective-model transfer.** Reuse an actual author Bose–Hubbard/iMPS ramp implementation if the main archive contains one; do not infer that from the archive name. Audit occupation truncation, units, time-dependent couplings, target sector, and leakage versus physical-observable error. Single-body paper Sec. V.B explicitly relates cold-atom occupation penalties to Gauss-law protection [R3]. Thermodynamic results offer an independent convergence reference, not a replacement ramp code [R1]. Proposed acceptance: reconstruct a documented author trace and its parameter mapping before extrapolating to a changed ramp. **Blocked for faithful replay if schedules/calibration or the relevant source are missing.**
3. **Open-bath spectrum-to-error-budget adapter.** There is an existing, explicitly identified implementation family: QuTiP Bloch–Redfield [N1–N3]. Add the paper's bath operators/spectral conventions to an already available model; validate physicality and solver controls. Distinguish fixed-rate Lindblad noise from frequency-dependent noise and coherent errors. This task's output is a noise model and its domain of validity, not another closed-system propagator. Paper-specific scripts/raw arrays: **not found**; the author thesis gives implementation details [N2].
4. **SU(3) LSH protection transfer against public author data.** Prefer this over an invented coefficient optimizer if `Dataset/` can be acquired and its schema resolved [D0]. Build a figure-data/constraint verifier and transfer the protection diagnostic from Abelian models to the LSH representation. Preserve global-charge means **and fluctuations**, local Abelian constraints, and averaging windows. Full dynamical reproduction remains conditional on requested author code or supplied matrices; do not label the data repository an executable solver. Exact reference and figure targets are below. This offers real author-data provenance and a distinct representation/validation task.

## Noise: existing implementation and discriminating references

- [N0] [2009.07848 PDF](https://arxiv.org/pdf/2009.07848): Eqs. (4a–b) specify `rho_dot=-i[H0+lambda H1,rho]+gamma L(rho)`; simulated channels are matter dephasing `L_m=n_j` and link `L_g=tau_z`. Gauge leakage crosses from `gamma*t` to `lambda^2*t^2` near `t~gamma/lambda^2` in the stated regime. Useful **white-noise/control reference**, not a colored-bath substitute. Specific public code: **not found**.
- [N1] [2210.06489 PDF](https://arxiv.org/pdf/2210.06489), *Suppression of 1/f noise in quantum simulators of gauge theories*: explicitly uses QuTiP, `L=4`, PBC; spectrum `S(omega)=gamma/|omega|^beta`, violation Eq. (8), U(1) operators Eqs. (9–10). Check early-time `epsilon~gamma*t/V^beta`, not indefinite coherent-error saturation. The U(1) example uses bath couplings `sigma_x` and spin-1/2 `s_x` (normalization matters).
- [N2] Same first author's [thesis 2403.14656, Sec. 3.3.2](https://arxiv.org/html/2403.14656v1): describes QuTiP Bloch–Redfield tensor/eigenbasis workflow and frequency callbacks. Eq. (3.11–12) supplies the tensor; validity check is `Gamma_if << |omega_if|`. No downloadable author script identified. Zero-frequency treatment and secular choices still need explicit recovery; do not silently invent an infrared regularization.
- [N3] Public [QuTiP Bloch–Redfield implementation](https://github.com/qutip/qutip/blob/master/qutip/solver/brmesolve.py) and [official theory/usage documentation](https://qutip.readthedocs.io/en/stable/guide/dynamics/dynamics-bloch-redfield.html). Reuse these; verify trace, Hermiticity, minimum eigenvalue, bath conventions and weak-coupling assumptions. Plain Redfield does not unconditionally guarantee positivity.
- Optional non-Dataverse author-data cross-check: [Mildenberger Zenodo 13142276](https://zenodo.org/records/13142276), linked by [the confinement experiment](https://www.nature.com/articles/s41567-024-02723-6), lists downloadable figure CSVs, including `source_data_ed_fig_6.csv` / `_7.csv`. **Source data, not verified code or bath-calibration records.**

## Coefficient certification: bounded fallback / component

Use exact arithmetic on physically allowed charge configurations, returning a resonant witness or minimum separation; no dynamical kernel is necessary. [R3] uses `H_prot=V sum_j c_j G_j`, with compliance `c·g=0 iff g=0`. [R2] replaces G with `W_j=tau_x(left)*tau_x(right)+2*g_tar*n_j`; Table I is an eight-configuration oracle and Eqs. (1–2),(5) define the target-sector equivalence. W is **not** a symmetry generator of H0. [R4] compares period-two `[6*(-1)^j+5]/11` to period-four `{-1,3,-7,17}/17`, distinguishing first-/second-order protection and global versus unit-cell compliance. Request its Fig. 8/9 data before quantitative benchmarking. Do not claim an unconstrained optimizer or a universal guarantee.
