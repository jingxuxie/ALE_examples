# Independent generic shortcut check

This is an author-side baseline of the existing ratcheted concept, not a new concept or a fresh model. It is fixed before seeing its outcomes and without inspecting the running confirmation attempt. Its executable receives only the same public participant files and unlabeled requests under the numerical filesystem sandbox. Strong masks, calibration values, and confirmation code are not mounted.

The algorithm reuses only the published starting optimizer's physics kernel and geometry factory. It replaces the coarse search with a fixed dimensionless triangular-profile grid: frequencies 2/1/3, amplitude-to-wavelength ratios 0.20/0.25/0.15/0.30/0.10, and nominal widths 100/140/180 nm. Frequency two is first because the public starting layout already has that frequency. No coefficient is fitted to a private source geometry. It uses the exact input operating points, successively checks 5/9/17 momenta with the public refinement helper, and performs a single ordinary amplitude/width coordinate refinement of two leading profiles. There are no pixel gradients or source optimizer calls.

It has the same 1200-second/two-core/6-GiB limits as a submission. Independent trusted scoring still uses 51 momenta and Pfaffian topology. Three invocations use CPU pairs starting at offsets 96/98/100, separate from confirmation grading. A valid cheap sweep that robustly reaches the strong reference is evidence against frontier-hardness even if a particular fresh attempt performs poorly. A timeout or coarse-grid overestimate is recorded, not treated as proof that every generic method fails.

No public file, reference, held-out case, or confirmation attempt is changed by this experiment. Results are stored separately in `private/runs/generic_probe/`.
