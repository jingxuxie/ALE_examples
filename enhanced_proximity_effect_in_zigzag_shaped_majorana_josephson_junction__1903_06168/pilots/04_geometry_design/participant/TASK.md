# Robust Josephson-junction geometry design

Design periodic superconducting contacts that improve the robust topological excitation gap beyond the supplied, unoptimized zigzag. Preserve manufacturable boundaries, connected contacts, and the required topological phase across the operating region. Generalize across the supplied device sizes and semiconductor/contact doping families within the stated compute budget.

Implement `solve.py` in the assigned writable attempt directory, accepting `--input REQUEST --output RESULT`, and return the contact geometry as JSON. The forward simulator is available in `workspace/`; it does not provide an optimizer. Treat geometry feasibility and efficient robustness evaluation as substantive parts of the task.

The authoritative physical model, output schema, constraints, resources, and scoring definitions are in `input/CONTRACT.md`.
