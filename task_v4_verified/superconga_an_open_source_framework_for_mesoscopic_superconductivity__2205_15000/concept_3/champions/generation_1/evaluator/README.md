# Private evaluator integration

Only `participant/` is distributable. Keep `evaluator/`, `attempts/`, `adversary/`,
`champions/`, and `status.json` private. The evaluator uses a frozen trusted copy
of the public forward model; submitted edits cannot replace grading physics.

The parent-provided `../authoring/sandbox.py` is imported exactly from the paper
root via `Path(__file__).resolve().parents[2] / 'authoring'`. Every episode calls
`Sandbox(participant, submission, seconds=90, memory_gib=2).start(...)` in a new
context. No `input_dir` is supplied: hidden seeds/scenes stay only in the host.
The helper supplies bubblewrap read-only mounts, private PID/network namespaces,
cleared environment, single-thread BLAS, writable `/output`, and resource limits.
The helper allows a small CPU-kill grace; the evaluator additionally fails any
completed episode reporting more than 90 child CPU seconds. Wall deadline is 120s.

The entry point executes `/usr/bin/python3 /submission/<entry>` with PIPE stdin,
stdout, stderr. The host sends public metadata only, validates one action at a
time, returns LDOS scalars, and grades the final estimate after a clean exit.
There is no in-process submission import, hidden callback, or hidden input file.
The host stdout/stderr drain is bounded; final output must be followed by clean
exit within three seconds. Runtime/traceback strings are never observations.

Run from `concept_3`, using an **escalated outer tool** so bubblewrap can create
its namespaces (restricted nested execution cannot unshare the network):

    OPENBLAS_NUM_THREADS=1 python evaluator/evaluate.py --split calibration --output attempts/baseline_calibration.json
    OPENBLAS_NUM_THREADS=1 python evaluator/evaluate.py --split evaluation --output attempts/baseline_hidden.json
    OPENBLAS_NUM_THREADS=1 python evaluator/evaluate.py --submission participant/workspace/my_submission --entry solve.py

Without submission arguments the shipped uniform baseline is run. A submission
root must contain `solve.py`; pass it with `--submission path/to/output`.
The report summary includes `core_score`, `worst_family_score`, `valid`,
`protocol`, and `reason` aliases. `runtime_score = max(0,1-mean_wall/120)` is a
separate speed diagnostic and cannot compensate for any reconstruction failure.
A submission
directory must not contain private evaluator files; do not mount the concept
root. `--limit N` is a smoke check, never an official passing result unless the
entire fixed suite was run. Train/calibration reports cannot confer official pass.
All output reports must remain inside this concept outside participant assets.

Development artifacts were generated by `build_assets.py`. The snapshot operation
emits an apply_patch patch and refuses to overwrite a frozen copy. Training and
calibration use disclosed seeds; hidden seeds are generated once from OS entropy,
then persisted. `frozen_manifest.json` records model, target, and seed hashes.
No seed rejection based on ease, target tuning on private performance, reference
solver comparison, or tested-agent launch is part of this task.

Validation commands:

    OPENBLAS_NUM_THREADS=1 python -m unittest discover -s evaluator -p 'test_*.py' -v
    OPENBLAS_NUM_THREADS=1 python evaluator/diagnostics.py

Integration/protocol tests need the same outer escalation as evaluation. Physics
and finite-candidate diagnostics require no network or privileges.
