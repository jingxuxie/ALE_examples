## What the recorded outcome means

These are saved author-reported screening outcomes, not a new independent
certification. Start with each report for its retained concept and generation,
achievability evidence, fresh-agent results, limitations, and rejected or
superseded concepts. The full saved task archive is retained, not only its winner.

The [selection record](SELECTION.json) accounts for all 21 tasks and the 18-plus-3
partition. [verify_collection.py](verify_collection.py) checks that coverage.
See the [publication notes](PUBLICATION.md) for snapshot semantics, omitted
launcher environments, external link declarations, and large-file restoration.
The [manifest](PUBLICATION_MANIFEST.json) records artifact hashes and provenance;
its paths are relative to this folder.

These bundles contain **privileged reviewer material**: solutions, witnesses,
hidden cases, and attempt transcripts. Give a blind participant only its chosen
participant assets, never the entire archive.
