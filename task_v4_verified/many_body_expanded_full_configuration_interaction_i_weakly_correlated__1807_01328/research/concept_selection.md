# Concept selection

Seed: Eriksen and Gauss, arXiv:1807.01328v2, especially Sections 2.1–2.2.
The original paper explicitly warns that signed incremental cancellation defeats a
successive-order stopping test. It does not assert a universal screening-error
bound. The experiments here are new stress tests, not alleged disproofs of a
theorem in that paper.

Nine concepts were considered before building the following three.

| Concept | Mode | Decision |
|---|---|---|
| Budgeted adaptive CAS experiment selection | E | Build: acquisition, nonlinear inference, and signed interactions under a query budget |
| Weak-correlation false-convergence counterexample | B | Build: constrained nonconvex search with independently reproduced spectra |
| Out-of-sample high-order correlation-tail prediction | D | Build: simulated outcomes, fixed held-out labels, family-wise accuracy |
| Adaptive screening implementation improvement | A | Not built: too close to active-query concept |
| Shared virtual-orbital clustering across geometries | C | Not built: arbitrary cost thresholds and too much dataset construction risk |
| Robust orbital rotation for MBE compression | C | Not built: natural-orbital diagonalization may solve a weak version |
| Distributed restart/screening repair in PyMBE | F | Not built: repository reproduction is not a good hardness source |
| Base-model acceleration reversal witness | B | Not built: clean CC reference conventions require a larger source-native installation |
| Cancellation-safe incremental accumulation | A | Not built: standard compensated summation can solve an overly narrow version |

The selected tasks use explicit, small pair-conserving electronic Hamiltonians.
They are deliberately labeled as model-system tests, not molecular Coulomb
integrals or reproductions of the paper's numerical tables. Full sector
diagonalization supplies exact, residual-checked outcomes. The hardness must come
from experimental information allocation, predictive generalization, or a
constrained counterexample search—not from implementing diagonalization.

Generation privileges: full Hamiltonians, all subset energies, private random
draws, expensive searches, and source inspection. Fresh agents receive only the
corresponding participant directory and an initially empty output directory.
