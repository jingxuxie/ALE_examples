# Private prospective scaling controls

These four finite Hamiltonians are outside the published generation-one domain.
No task generation, target, evaluator, public asset, or fresh submission is changed.
They test the archived champion at 40 CPU seconds against independently measured
same-cap variational states from a more expensive solver. Masses are heuristic
coordinates, not certified finite-basis critical points.

The private runtime copies infra5 exactly except for increasing the file-size
and NPZ-validation limits to 64 MiB. The Hamiltonian, contractions, parity checks,
CPU/wall accounting, one-thread restriction, and 2 GiB memory limit are unchanged.
Any future public generation using these lengths must explicitly declare its
larger domain and artifact limits and perform a new cold-baseline admission.

Neither resource failures nor results from this unpublished domain are scored
against generation one. Every retained energy is recomputed from an actual MPS;
no reference is asserted to be an exact ground energy or a budget-feasible solver.
