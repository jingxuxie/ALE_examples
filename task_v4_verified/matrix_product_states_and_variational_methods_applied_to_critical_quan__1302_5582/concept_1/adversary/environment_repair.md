# Pre-tournament execution-environment repair

No A participant attempt had been launched when this repair was made. The first generator-side weak baseline hit a ten-second wall guard after only 0.024 CPU seconds. This was filesystem/setup latency, not scientific solver difficulty and is excluded as hardness evidence.

The trusted runner now stages the entire submission and public assets to local `/tmp` before starting timing. The staged files are the only task mounts, with the original public path mapped to its staged read-only copy for import compatibility. Private references and evaluator sources are absent from the child. CPU accounting, affinity, memory limits, quality targets and Hamiltonians are unchanged. A trusted bootstrap installs fail-closed seccomp rules before running submission code, enforcing the documented prohibition on child processes and external commands.

Artifacts are copied back only after checking that they are ordinary, non-linked files. A repeated short-stage timeout after local staging reported just 0.095 wrapper CPU seconds in ten wall seconds. Later tests showed that wrapper wait4 usage did not reliably include the solver descendant. CPU accounting is therefore moved to a protected supervisor inside the sandbox, which waits directly on the solver and writes its true CPU usage after the solver exits. The child cannot modify supervisor memory or replace the inode of the final accounting report without invalidating the run. Child process creation remains blocked after trusted setup.

To avoid contention on the same lowest-numbered CPU across unrelated benchmarks, hard affinity is removed. Pre-launch wall guards are widened to 30/120 seconds; scientific 6/40 CPU-second budgets and quality targets are unchanged. The weak baseline's active bond and eigensolver effort are reduced before recalibration so it can satisfy its own short budget. No fresh A attempt has been run, and no old calibration is reused after these changes. These failures are evaluator/baseline integration issues, not evidence of scientific hardness.
