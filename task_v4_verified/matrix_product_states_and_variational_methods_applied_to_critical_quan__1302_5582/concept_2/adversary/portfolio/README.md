## Construction

`optimize.py` uses two parity-sector QR row isometries, a differentiable linear
solve for the thermodynamic stationary density, and explicit transfer recursion
for every requested correlation. L-BFGS energy minimization grows the bond
dimension through 4, 8, 16, and 24. A second stage fits the actual multiscale
observables while retaining low energy. No exact-ground-state formula or
preexisting solution tensor is used to construct the submitted state.

For seed 17, the energy-only D=24 checkpoint has lower energy excess
(1.1674825570739955e-6) but fails xx with 12.530829600019588% maximum relative
error. Multiscale fitting reduces that to 0.33687173338967646%, while keeping
energy well inside the bound. This distinction is why the energy-only checkpoint
is not accepted as the witness.

The successful seed-17 run logged 35.17 seconds of solver/checkpoint wall time,
excluding process startup. The allowed extra 30–45 minutes were not needed.

Reproduce from this directory with:

```sh
PYTHONDONTWRITEBYTECODE=1 python optimize.py --validate
PYTHONDONTWRITEBYTECODE=1 python -u optimize.py --name reproduction --seed 17 --seconds 1350 --energy-iterations 600 --fit-iterations 1200
PYTHONDONTWRITEBYTECODE=1 python ../../evaluator/evaluate.py --submission . --output exact_checker_score.json
```

Achievability means satisfaction of the frozen finite set of numerical witness
conditions. It does not assert that the finite-D state is the exact critical
ground state at all distances.
