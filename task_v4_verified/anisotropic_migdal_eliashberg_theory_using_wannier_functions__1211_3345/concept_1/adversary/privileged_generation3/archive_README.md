# Private generation-three achiever

`frozen_submission/` is the minimal runnable three-file solver, byte-identical to
the source used for both passing active-generation-three full-suite evaluations.
This is privileged authoring evidence and must not enter participant assets or
the ongoing fresh-v5 trial.

`evidence/` contains two unchanged twenty-case reports, their exact-command and
dataset/seal provenance, eight operator regression checks, a fixture-free source
audit, the bounded protocol, and the final sidecar summary. `provenance.json`
hashes this bundle and identifies the active generation-three 98-file prelaunch
seal and dataset manifest independently of the shared physics-policy hash.

To replay privately, invoke the active `concept_1/evaluator/evaluate.py` with
`--submission` set to the canonical absolute path of `frozen_submission/` and
`--report` set to a new private output path. Use the unchanged 12-CPU-second,
2048-MiB, one-thread gates. Never mount the archive root as a submission: its
`evidence/` directory is private and unnecessary for inference.

The solver uses only runtime input: exact full Fourier fusion, compressed
prefix-moment coarse kernels, and exact full-grid residual corrections. The
earlier v4 few-mode method remains intact. It contains no references, stored
solution arrays, case identifiers, or fixture lookup. This archive demonstrates
same-budget joint attainability; the separate fresh-v5 result is parent-owned.
