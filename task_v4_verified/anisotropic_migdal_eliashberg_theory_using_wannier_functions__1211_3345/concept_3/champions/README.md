# Privileged inference attempts

No passing, runtime-qualified v2 champion is known. `portfolio/` is an expensive
feature-only domain-structured reference: a public-seed model bank, multiple
bounded fits across compatible families, a Gaussianized latent prior, and
likelihood-weighted averaging of near-best fits. It never reads hidden labels
or generating parameters. The private audit passes core but narrowly misses
worst-family accuracy on 12 cases and does not satisfy the full-batch runtime.
See `../evaluator/hidden/blind_audit.json`. Label replay is scorer sanity only.

V1 is retired and archived; it is not the current target. This directory is
private and should not be published with the participant package.
