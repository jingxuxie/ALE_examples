# Private concept selection

This file and every generation artifact are excluded from tested-agent mounts.

Eight concepts were considered before building three:

1. Robust finite-degree damped-rational interpolation node optimization (A).
   Select: shared nodes across uncertain prefactors and worst-family peak error
   require nontrivial numerical design, not the asymptotic density formula.
2. Falsifying a multi-stage continuous matrix-positivity screening procedure (B).
   Select: require exact negative Rayleigh evidence despite several independent
   numerical searches; no parsing, overflow, or scalar-grid-only loophole.
3. Compact rational matrix sum-of-squares certificates on the half-line (C).
   Select: low-rank boundary faces, polynomial nullspaces and scale separation
   couple exact algebra to nonconvex factor recovery. Private planted witnesses
   demonstrate existence without furnishing a participant reference solver.
4. Matrix-valued atomic spectral-measure recovery from noisy moments (D).
   Defer: identifiability and noise-floor calibration would need a larger audit.
5. Query-budgeted reconstruction of thin PMP feasibility islands (E).
   Defer: distinguishing simulator geometry from physically meaningful hardness
   would require substantially more source-native data generation.
6. Repair of SDPB spectrum indexing and higher-rank OPE extraction (F).
   Reject as primary: known indexing fixes and upstream patches are too direct.
7. Block scheduling and precision allocation for distributed Schur complements
   (A). Defer: shared-host timing makes resource comparisons less trustworthy.
8. Recover exact feasibility separators for a shifted PMP atlas (C).
   Reject as primary: a previous local task already uses this formulation and
   its small cones reduce too directly to a standard conic solver.
9. Implement the new optimal sampling-density formula (A).
   Reject: reproducing an existing package or a complete formula is not enough.

The three selected concepts use different primary verification modes A, B, C.
Thresholds and participant/evaluator hashes are frozen before each launch.
