# Private pre-decision audit

## Physical validity and artifact provenance

The official code is unchanged except for the separate benchmark adapter; there
are no injected sign errors or deleted implementations. Meshes use actual
package-layout polygons for the IBM sensor and reconstructed canonical devices
from the source workflow. The material and close-spacing cases extend the
paper's explicit multi-film and variable-Lambda regimes, rather than replacing
the forward workflow with synthetic parameter inference.

Every hidden hole is strictly contained in its exterior polygon, with positive
clearance. The official-layout legacy failure is a generated fluxoid-contour
failure, not an invalid input hole: the two minimum physical clearances are
0.4491 and 0.1647 um. The legacy routine's automatically expanded contour does
not completely enclose one of these irregular holes. The resolved topological
description remains unambiguous.

The reference has independent analytic-vs-adaptive triangle integration checks,
order-6 versus order-10 assembly checks, positive definite operators, reciprocal
responses and exact controlled-state constraints. Separate continuum checks
against the real digitized ring-inductance curves differ by 1.4–4.2% on the
coarse public mesh. The kinetic-annulus asymptote differs by 1.5%. These checks
are not hidden scoring tolerances: the public contract explicitly distinguishes
the fixed resolved P1 model from continuum mesh convergence.

## Independence and isolation

The paper, supplementary notebooks, oracle arrays, reference implementation,
candidate review, evaluator and logs are outside the participant allowlist.
The child is launched with the exact requested model, a fresh ephemeral session,
the provided allowlist launcher, and no approval escalation. Its transcript
records the model and session ID. Only the current participant and output roots
are granted project-file access; offline dependency files are inside the former.
The transcript itself is saved outside those roots.

Evaluation uses a second filesystem/network isolation layer. It mounts one
staged input plus the submission and participant tree, never oracle outputs.
The trusted grader uses private copies of input files and Python summary code.
Public dependencies were copied without sharing writable hardlinks to the
trusted dependency snapshot. Task and evaluator source hashes were frozen
before launching the scientific attempt. The launcher was subsequently made
more robust by explicitly closing inherited stdin for future rounds; this did
not change the active session, task, numerical score or evaluation criteria.

## Outcome, not clerical scoring

Core score combines six distinct geometry/material/topology/source regimes,
spatial accuracy and conservative consistency. Runtime and measured resident
memory are separate dimensions. Evidence scoring reruns configurations and
checks quantitative claims against raw arrays and tables, not image aesthetics.
The reference completes the isolated evaluation with core 0.999676, overall
0.997681 and complete evidence consistency. Reference cases run in a few seconds,
far below the 60-second process guard and 3600-second agent budget.

The strongest remaining shortcut risk is constructing one conservative Galerkin
energy operator, using analytic triangle integration, and solving the constrained
linear system. This was not considered a sufficient shortcut by inspection
alone because it requires integrating material, topology, multilayer coupling,
sources and vector readout. The empirical attempt must decide whether that
integration is actually difficult for the requested frontier model. If it
achieves near-reference accuracy, reject; do not add hidden complexity or tighten
the score to rescue the concept.
