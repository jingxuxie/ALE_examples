# Physical and executable contract

All quantities use dimensionless consistent angular-frequency/time units and
ħ=1. Each JSON describes one experiment and points to a neighboring NPZ file.
NPZ keys: `dt[S]` (strictly positive segment lengths), `H[S,d,d]` (the actual
piecewise-constant control Hamiltonian), `operators[C,d,d]`,
`sensitivity[S,C]`, `blocks[G+1]` (segment boundaries, including 0 and S),
and `computational[q]` (indices of the computational subspace). Nothing in a
file name is a physical convention. In particular the six-state devices must
not be silently projected into a closed four-dimensional Hilbert space.

The stochastic Hamiltonian on segment s is

    H_s + sum_a sensitivity[s,a] * operators[a] * beta_a(t).

`beta_a(t) = sum_m mixing[a,m] x_m(t)`. Latent x_m are independent and have
zero mean. The `noise` object supplies all their parameters:

- `static`: one Gaussian draw with standard deviation sigma[m], held fixed
  throughout an entire record (not redrawn at block boundaries).
- `ou`: stationary Gaussian Ornstein-Uhlenbeck, covariance
  sigma[m]^2 exp(-rates[m] |t-s|).
- `telegraph`: stationary symmetric ±sigma[m], with independent Poisson
  sign changes of rate rates[m]. These are not Gaussian processes.
- `white`: Gaussian white noise in the Stratonovich convention,
  E[x_m(t)x_n(s)] = delta_mn sigma[m]^2 delta(t-s).
- `broadband`: independent Gaussian OU components with the same definition
  as `ou`, but many components spanning logarithmic correlation times. This
  is a rational, finite-band model of colored charge noise, not a white or
  quasistatic process. The operating amplitudes are small. Entries `rates`
  and `sigma` define the complete model; do not infer them from names.

The noise is stationary at time zero. Independent experiments receive new
draws, but the noise memory is continuous within one experiment. `blocks`
denotes a gate-library partition, not an operation on the bath.

## Quantities to deliver

`channel` is the ensemble mean laboratory-frame superoperator Φ. Column-major
vectorization is used throughout: vec(UρU†) = (U.conj() ⊗ U) vec(ρ). Its shape
is (d²,d²); complex arrays are allowed. The ideal channel Φ0 is generated by
the supplied H, not by a named target gate, and the error channel is Φ0† Φ.

`k2` is the quadratic response in the **initial interaction frame**. If all
sigma entries are multiplied by a real λ, then

    Φ0† Φ(λ) = I + λ² k2 + O(λ⁴).

Thus `k2` includes the stated noise amplitudes and its coherent part. It is
not a fitted depolarizing rate. The two deliverables distinguish an accurate
small-noise response from an accurate finite-noise channel. For the broadband
records, the same exact stochastic target is used; weak amplitudes make a
controlled approximation legitimate if its residual is demonstrated.

`baseline` must retain the supplied predictor behavior for comparison.
`selected` is your release implementation. `refined` is your genuinely tighter
numerical/convergence setting, not an alias of selected. `no_memory` evaluates
your chosen physical method with independent bath restarts at each `blocks`
boundary; for white noise this should be equivalent to the continuous bath.
It is an ablation, not the physical target.

Invocation: `bash output/run.sh CASE_JSON DESTINATION --mode MODE`.
The entry point must work from another directory and on new files. Write
`DESTINATION/process.npz` with arrays `channel` and `k2`, and
`DESTINATION/metrics.json` with `case_id`, `mode`, `seconds`, `peak_rss_mb`,
`infidelity`, `leakage`, `coherent_size`, `tp_error`, `unital_error`,
`choi_min`, `k2_norm`, and a free-form `diagnostics` object identifying the
actual method and numerical settings. `pipeline.physics.observables` defines
the public scalar metrics; the evaluator recomputes them independently.

Complex channel error is scored relative to ||Φ−Φ0||_F (floor 1e-8) and
quadratic error relative to ||k2||_F (floor 1e-8). Mean and worst-family
performance both matter. Improvements below one percent remain valuable;
physicality alone and just matching average fidelity are insufficient.
Runtime and peak memory also matter: the reference completes a case within
60 seconds, with less than 1.5 GiB RAM, on one CPU thread. A hidden invocation
is stopped at 120 seconds or 2 GiB. These are operational system budgets,
not the time allowance for developing your solution.
