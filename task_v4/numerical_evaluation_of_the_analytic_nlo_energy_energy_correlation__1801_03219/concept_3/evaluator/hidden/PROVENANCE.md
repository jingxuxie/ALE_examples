# Private scale-ratchet provenance

Generation 2 preserves the same finite inverse two-point EEC witness problem
and the same 3600-second external budget. It scales pair count, label counts,
and total integer energy by eight: 512 to 4096 pairs, 64/32 to 512/256 nonzero
labels, and sum 128 to 1024. The occupied fraction and nonzero label ratio are
unchanged, as are the empty-neighbor rule and exact full-autocorrelation goal.
This is a larger native search space, not an added hidden observable or trivia.

The main session reported a provisional generation-1 exact solve and requested
this private staging. No active outputs or solver code were read. No RRR,
champion, fresh-agent, or scale-sweep run was performed here. Those comparisons
and the archive/install decision belong to the main session after current
attempts finish. Do not promote based on bounded local-search failure alone.

The physical definition follows the ordered-pair EEC, including self-pairs, of
arXiv:1801.03219 equations (1)–(2). The event is synthetic and kinematic, not
an NLO QCD continuum calculation or a statement about perturbative multiplicity.
The full direction sequence repeats the pair energies, so all momenta are
massless, antipodal momenta cancel, and exact rational EEC mass sums to one.

One unseeded SystemRandom feasible support/label assignment is drawn using
cyclic gap composition. It is frozen before any baseline test and never
selected or resampled based on solver performance. Only its full target
autocorrelation is public. The planted coordinates and their hash stay private.
The evaluator uses a separately frozen validator snapshot and target; it never
reads the planted witness during ordinary grading.

The independent audit compares exact NumPy sparse-pair accumulation against
the grader's native integer sums and FFT reconstruction, and reconstructs the
entire 8192-bin directed and 4097-bin geometric angular histograms. Efficient
score-vector mutations test lag enforcement without repeating expensive spatial
autocorrelation for every lag. Audit independence is computational, not an
independent agent review. The baseline uses the same 240,000 proposed swaps as
the smaller reference run, with size-scaled annealing temperatures and linear
working storage; this is not an equal-proposals-per-slot experiment.
