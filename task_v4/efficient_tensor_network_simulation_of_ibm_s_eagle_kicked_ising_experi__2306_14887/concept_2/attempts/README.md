# Generation evidence

All searches here are privileged builder computations, not model attempts.
`explore.py` scans several public physical observables before choosing `zz1`.
`refine.py` uses six interpolated global pulse controls and five perturbations.
Early exploration/refinement files predate deterministic Schmidt tie-breaking;
only `stable_refinement_2.json` and final evaluator reports concern the frozen
algorithm. They must not be mixed when comparing scores.

`baseline/` is generated by the public, fixed-seed 48-trial baseline.
`self_check.json`, `final_self_check.json`, and `evaluator_audit.json` record
simulator and checker evidence. No fresh model is invoked by this package.
