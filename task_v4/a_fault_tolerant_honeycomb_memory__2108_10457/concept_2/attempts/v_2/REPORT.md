# Submission status

`design.json` is a regular 62-byte file with the required schema. **The requested
improvement and pass target were not achieved.** The best alternate construction
found is a spatial reflection of the supplied champion, not a genuinely improved
construction. It is retained as the strongest alternate artifact found, without
claiming that it satisfies the task's improvement requirement.

`verify_symmetry.py` verifies preservation of both joint-response and
syndrome-only linear relations under `(x, y) -> (width - x, y)` for every supplied
response column on all three sizes. This reflection exchanges the submitted and
baseline patterns. Consequently they have identical correctability distributions
under IID erasures; observed score differences are sampling variation.

## Search and verification

- Built an accelerated exact GF(2) evaluator, retaining all four logical bits.
  It agrees with the supplied Python evaluator on all sizes and random patterns.
- Ran randomized annealing and local search with independent training batches.
- Enumerated all 116 perfect matchings of the 24-site colored measurement graph.
- Exhaustively screened Hamming neighborhoods through radius four around the
  baseline and independently rescored their strongest candidates.
- Implemented branch-and-bound over all `3^24 = 282429536481` assignments.
  Adding sites cannot restore correctability to a failed support, so partial
  assignments give valid upper bounds on the number of correctable supports.
- Verified branch-and-bound against brute-force enumeration on twelve restricted
  configurations, each starting with 729 designs, using two variable orders and
  optional symmetry reduction. All survivor sets and correctability counts
  agree; see `bounded_tests.log`.
- Rescored candidate constructions on independent batches across sizes and
  densities. No genuinely different candidate improved upon the champion.

## Reproduction

Run from this submission directory:

```sh
export P="$PWD/../../participant"
export PYTHONDONTWRITEBYTECODE=1
export PYTHONPYCACHEPREFIX="$PWD/pycache"
export TMPDIR="$PWD"
python "$P/workspace/check_design.py" design.json --seed 914731 --count 4096
```

To rebuild the accelerated evaluator and run the branch-and-bound regression
checks:

```sh
python prepare.py
g++ -O3 -march=native -std=c++17 -shared -fPIC evaluator.cpp -o evaluator.so
g++ -O3 -march=native -std=c++17 bounded.cpp -o bounded_test
python test_bounded.py
python verify_symmetry.py
```

For example, the independent 128-support exhaustive screen is reproduced by:

```sh
g++ -O3 -march=native -std=c++17 -DSAMPLE_COUNT=128 bounded.cpp -o bounded128
./bounded128 62 .32 861296347 bounded128 0
```

Only `design.json` is the evaluated artifact. Other files are development code,
logs, or validation results. Intermediate interrupted runs are not claimed as
completed exhaustive searches.
