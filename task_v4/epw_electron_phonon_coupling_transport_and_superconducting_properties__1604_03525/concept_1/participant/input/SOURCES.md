# Primary sources and scope

1. S. Poncé, E. R. Margine, C. Verdi, F. Giustino, *EPW: Electron-phonon
   coupling, transport and superconducting properties using maximally localized
   Wannier functions*, Computer Physics Communications 209 (2016), 116–133,
   arXiv:1604.03525v2. Equations (12), (16)–(19), (32)–(34) motivate the
   spectral density, its moments, approximate Tc, and imaginary-axis kernel.
   Primary manuscript: `https://arxiv.org/pdf/1604.03525`.
2. P. B. Allen and R. C. Dynes, *Transition temperature of strong-coupled
   superconductors reanalyzed*, Physical Review B 12 (1975), 905,
   DOI `10.1103/PhysRevB.12.905`. Strong-coupling corrections discussed there
   are deliberately NOT used in the benchmark's simplified Tc diagnostic.

Sources checked 2026-08-28. The inverse population, stochastic observation model,
split sizes, metric and thresholds are benchmark design choices, not claims made
by these papers. This task does not run EPW or reproduce a named material.
