# Trusted evaluation

Run `python3 evaluator/evaluate.py --submission OUTPUT_DIRECTORY --report report.json` from the concept root, or pass the full path to `OUTPUT_DIRECTORY/circuit.json`. Only that top-level static artifact is read; no participant Python, shell, pickle, imports, plugins, or commands execute. `evaluate(attempt_directory)` has the same directory-to-artifact behavior. The evaluator imports only its trusted adjacent checker and reads `evaluator/hidden/instance.json`, never the public instance or private witness. The canonical feasibility witness is `evaluator/hidden/witness/circuit.json`; its provenance is also private. Valid-but-over-budget circuits receive fractional scores; acceptance requires exact signed equality and all budgets. Participant assets, including the initial workspace artifact, are read-only; the runner supplies a separate writable attempt/output directory.

Evaluation uses a fresh isolated Python interpreter, one CPU, 512 MiB address-space limit, 10 CPU seconds, and 15 wall seconds. The regular-file descriptor is opened with no-follow and passed directly to the worker. Oversized artifacts, final symlinks, FIFOs, duplicate keys, invalid JSON, non-native gates, invalid topology, overlapping layers, wrong phases and count violations are rejected. This is a bounded data evaluator, not an untrusted-code sandbox.

Export only `participant/` to a solving environment. Keep this directory, `hidden/`, `adversary/`, all reports, and the parent `authoring/vendor` inaccessible and read-only to participants. Filesystem separation is a runner responsibility; no fresh-agent isolation run has been performed. A parent-path or hardlink to a private file must not be made available by the runner. File permissions alone do not isolate same-UID agents.

`hidden/generate.py` uses the already pinned private Stim 1.15.0 and refuses to overwrite a frozen target. `hidden/selftest.py` compares independent exact Python phases against native Stim and exercises the actual limited evaluator. These are authoring-only scripts, not participant dependencies.
