# Anti-compression assessment — before construction

## Intended independent work

1. Compile local operator sums with coherent cancellations and target-sector
   reachability. U1 uses additive, staggered spin-half Gauss constraints and a
   forbidden adjacent-flux pattern. Z2 uses a multiplicative parity constraint,
   an electric-X basis, and state-dependent pseudogenerator transfers which
   cannot be reconstructed from the violated-generator set alone.
2. Synthesize a finite-alphabet coefficient vector under site-dependent hardware
   ranges and coefficient uncertainty. Correlated local errors frustrate simply
   reusing a constant or staggered vector. This is discrete optimization, not a
   time-evolution/exponentiation problem.
3. Synthesize a separate digital vector and allowed kick phase against circular
   quasienergy aliases. A large analog gap can be an exact digital resonance.
   Reusing the analog answer without modulo-2pi analysis is not sufficient.

Certificates and synthesized-control quality are scored separately. The judge
computes robustness from private physical transfers, never from submitted rows.
Full rings have 32–160 sites and 64–320 binary degrees of freedom; only local
factorization is appropriate. Tiny exhaustive Hilbert checks are validation,
not the intended large-case algorithm. Cases cover U1 elementary errors, U1
correlated errors, and Z2 pseudogenerators, each with analog and digital outputs.

## Likely compression attacks and honest limits

* A universal local matrix engine can help compile both models, but must still
  implement different target-sector conditions and distinct G and W maps.
  Once compilation succeeds, both yield sparse linear forms; that common
  interface is physically intrinsic and is not hidden or claimed to be hard.
* Translation caching is intended. A period-two answer may solve elementary
  analog cases. Correlations, calibration masks, and phase windows are intended
  to test whether it generalizes; their success must be measured, not assumed.
* A capable generic discrete optimizer could solve every family in 60 seconds.
  If a fresh generic participant robustly attains high mean AND worst-family
  scores, discard this pilot rather than manufacturing post-hoc traps.
* Frozen known constructive references are feasible witnesses, not proven global
  optima. Better submissions continue improving the smooth score above them.
* A certificate-only solution must not receive a good overall score. Conversely,
  a numerically good control vector does not excuse an incorrect sector map.
* Do not include references, private cases, labeled development answers, or the
  judge in the participant export. The local evaluator is a trusted-code runner,
  not a filesystem security boundary; use main's isolation for untrusted agents.

## Precommitted validation

Freeze nine screening cases, a larger challenge pool, and a separately seeded
reserved confirmation split before participant runs. Record hashes and weak /
strong anchors. Validate both algebra and local analog/digital gap certificates
against independent tiny explicit tensor-product Hilbert enumeration, including
boundary wrap, forbidden U1 states, Z2 G-versus-W mismatch, destructive channel
interference, and a digital alias. Report mean and worst-family, not just mean.
Reference must exceed 0.9; a weak published-pattern baseline is measured using
the same physical oracle, with perfect certificates to isolate synthesis.
