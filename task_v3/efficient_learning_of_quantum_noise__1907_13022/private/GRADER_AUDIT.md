# Evaluator integrity notes

- All model attempts use the supplied filesystem-allowlisted runner, `ultima-alpha`, xhigh reasoning, web search disabled, and a 3,600-second wall limit. A nonempty sparse attempt directory initially contained only a one-byte `.gitkeep`; the preflight rejected it before any model launch. The placeholder was removed and a genuinely empty attempt directory used. This was not a failed model attempt.
- Strong references are executable input-only solvers, independently checked against small exact calculations or known physical channels. Stored targets avoid expensive reference computations during grading. Numeric subprocesses are limited and receive a staged single-file solver and input only.
- Landlock isolation was tested through both `/srv/home/...` and `/home/...` aliases. Runtime imports and scratch writes work, while private-source reads fail. Graders fail closed if confinement is unavailable.
- Gateset, sparse and graphical graders already check bounded numeric output archives and prevent parent-side symlink readback. The experimental grader received the same parent-side no-follow and bounded-shape parsing after the model launched, before any submitted solver was scored. This changes no cases, target arrays, losses, thresholds or public contract; it only closes an output-file access channel. Original prelaunch hashes are retained in run metadata, so this security-only amendment is not hidden.
- No evaluator gives scores, labels or counterexamples back to an in-progress first-round model. Finished submissions are frozen by content hash before hidden evaluation. Each later confirmation receives only its versioned participant tree and a new empty attempt directory.
