# Privileged source-derived reference

The executable is **not** a full VAMPIRE build or an invented replacement transport algorithm. `engine.cpp` includes the official serial `sublattice-resistance.cpp`, `sublattice-magnetization.cpp`, and `field.cpp` implementations at `e3c8ab8dd672c1725cd10558962ee7096e1e999d`. Upstream files are retained verbatim, with SHA-256 digests and exact URLs in `provenance.json`.

`instrumented_resistance.cpp` differs from upstream only by three observation assignments: one saves an effective channel resistance, two save returned cell resistances. The equations and stack traversal are unchanged. `engine.cpp` adapts the count-mean, fractional-area, and inverse-moment initialization from the retained upstream initialization routine to a supplied SI atom list. It computes the separately specified atomwise LLG tangent derivative after calling the official field mapper. JSON/text conversion is performed by `solve.py`.

The initialization adapter deliberately does not expose nonmagnetic-remove atoms, empty whole cells, irregular physical grids, MPI decomposition, or arbitrary endpoint occupancy. Every sublattice must be magnetic at both stack endpoints. This also prevents persistence of a previous stack's upstream-polarization scratch values for absent entrance channels. Interior missing channels are supported and tested. No long-time dynamics, thermal noise, spin diffusion, or ab-initio accuracy is claimed.

## Reproduction

Run `sh private/reference/rebuild.sh` from the transport root, then `/usr/bin/python3 -s private/reference/solve.py CASE.json OUTPUT.json` for a trusted local reference calculation. No VAMPIRE checkout modifications or external libraries are needed for the C++ engine. The wrapper uses only the Python standard library.

`oracle.py` is an independently written NumPy implementation of the specified equations. Frozen expected arrays are generated by it and cross-checked with the official C++ reference for every case, rather than being self-comparisons of the reference binary. `independent_validations.json` records the analytic two-cell check, differential errors, current conservation, tangent derivatives, and metamorphic checks. All validation statements must be read together with that actual generated artifact.
