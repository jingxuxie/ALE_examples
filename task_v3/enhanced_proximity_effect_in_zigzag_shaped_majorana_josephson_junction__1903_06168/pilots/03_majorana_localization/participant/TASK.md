# Localization beyond a finite device

Build a reliable localization-analysis program for the supplied superconducting-junction simulations. Recover bulk amplitude decay lengths and isolate finite-device left-end density profiles, including their decay lengths. Handle overlapping ends, oscillations, and changes of basis without changing the physical device.

Start from `workspace/finite_workflow.py`. The complete definitions, file formats, and scoring are in `workspace/DEFINITION.md`. Submit `attempt/solve.py`, runnable as `python attempt/solve.py --input INPUT --output OUTPUT`.
