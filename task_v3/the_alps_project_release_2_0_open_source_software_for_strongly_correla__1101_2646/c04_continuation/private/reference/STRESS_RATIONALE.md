# Additional source-grounded challenge region

This is a challenge-pool extension, not a ratchet and not a new pilot concept. It leaves the public contract, broadening, data precision, runtime, output fields, and scoring unchanged.

The original matrix-continuation paper and official Carathéodory implementation permit general complex matrix Green functions. The initial dispersive models have complex orbital rotations but an underlying time-reversal-compatible real representation. The added models have a complex hopping loop and momentum-dependent orbital hybridization. A nonzero imaginary trace of a product of three Hermitian Bloch Hamiltonians certifies that they cannot all be made real by one fixed orbital rotation. Thus these test genuine matrix structure, not extra rows or a tighter tolerance. They remain finite-range Hermitian tight-binding models with positive spectral measures and exactly known moments.

References use the same independent spectral-resolvent construction as the initial cases. The grid is independently increased from 160×160 to 256×256, and the checks are stored for each input. No submitted algorithm has been used to choose an answer. Whether this region is a counterexample is decided only by running the completed frozen submission. Any later ratchet must use different held-out Hamiltonians.

Primary basis: arXiv:2107.00788 and the retained official `Caratheodory_kernel.cpp`. This is a physical-family extension authored for evaluation, not a claim that these particular Hamiltonians or reference arrays were distributed by those authors.
