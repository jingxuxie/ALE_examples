# Reference provenance and limitations

This is a later-capability/privileged-output pilot, not a verbatim historical bug patch. The public single-pole adapter is author-written; it is not falsely represented as ALPS source. The missing capability is full matrix continuation and its Dyson compatibility, documented in Fei, Yeh, Zgid, Gull, arXiv:2107.00788. The official TRIQS/Nevanlinna implementation is retained privately under the root `private/sources/Nevanlinna`. It is solution-bearing and is not mounted for participants.

The stored real-axis answers are precomputed spectral resolvents of hidden Hermitian impurity and tight-binding Hamiltonians, following the directly evaluable models used in the official Nevanlinna tutorials. They are not outputs generated by the public scalar baseline. Finite-system eigenvector/residue answers are independently checked against direct full-matrix inversion; moment sum rules and positive spectral eigenvalues are verified for every case. These are category-5 privileged high-quality outputs, not a claim that the complete TRIQS stack was compiled here.

The independent published `baryrat` AAA implementation is retained as an explicit universal-shortcut diagnostic. The initial core diagnostic reconstructs both finite-pole families essentially exactly, but fails a matrix continuum case through substantial negative spectral weight and off-diagonal error. This is an empirical observation, not sufficient by itself for acceptance. The fresh-agent pilot and continuum identifiability checks still control selection.

Do not accept a continuation ratchet merely because finite imaginary-frequency data underdetermine an arbitrarily sharp real-axis spectrum. All targets use a stated positive broadening. A retained version additionally needs reconstruction evidence at that resolution and independent band-grid convergence. If a source-grounded recoverable failure region cannot be demonstrated, reject this concept.
