# Real-acquisition reconstruction gap

Private source: official Juqst `src/marginal.jl` (`fitTheFidelities`, `projectSimplex`, `conditionalMutualInfo`, `gibbsRandomField`) and `docs/examples/quantumNoise/{SingleQubitProtocol,TwoQubitGatesRuns}.ipynb`. The starting artifact is a neutral data adapter and naive baseline, NOT a claim to be an exact historical checkout. The later complete analysis implementation is withheld.

Official data: `rharper2/EfficientLearningDataSet`, also distributed in Juqst's quantumNoise data directory. The four acquisitions are the single-qubit protocol and three simultaneous two-qubit configurations on 14 qubits. Counts have not been generated by a synthetic noise simulator. Truncated acquisition windows are marked explicitly in the manifest. They are not independent new experiments, and will not be represented as such.

The reference ports the source's early-decay cutoff, bounded two-parameter exponential objective, simplex projection, conditional information and conditional-factor reconstruction. The separable fit is minimized by vectorized scalar search, independently checked on 32 modes per acquisition against SciPy bounded least-squares. Reference values are trusted reconstruction targets, not noiseless ground truth of the physical device. This distinction matters for accepting or rejecting a counterexample: a mere difference between sensible fit policies is NOT sufficient evidence of hardness.

Anti-compression: nonlinear decay regression does not implement the histogram transform, physical channel projection, categorical conditional information with unequal group cardinalities, or spatial-model validation. Four core components are separately scored. A dense full-channel method is allowed at the source experiment's real 14-qubit size; this pilot does not pretend scale alone makes it hard.

Scoring: each component receives `scale/(scale+loss)`, where `scale=0.12*weak_baseline_loss+absolute_floor`. This has no clipping plateau, gives the reference 1, and is continuously informative below the weak baseline. The nonidentity distribution loss excludes domination by the identity spike. Runtime is recorded; each case has a 120-second, 3-GiB cap.

Ratchet candidates must be genuine real-data mismatch or conditional-factor failures, not column renaming, a stricter cutoff-matching tolerance or additional random queries. If a generic correct pipeline succeeds, reject this concept.
