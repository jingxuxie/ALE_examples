A relative residual allowance of 0.22 permits a dominant atom amid much smaller collisions; this is an explicit heuristic adaptation, not a source theorem. The less brittle allowance recovers support first; global nonnegative refinement then estimates probabilities.
- `peel.jl:396` (`peelBack`): subtract the recovered signed atom from its corresponding bin in every group. Refit all discovered amplitudes with nonnegative least squares, then rebuild residuals. This avoids the source's explicitly questioned duplicate-value update logic and controls dynamic-range error propagation.

These are adaptations of an available algorithm, not claims of a verbatim Julia port or a new theorem. General commuting hash rows are generated by explicit Clifford H/S/CNOT updates from independent coordinate generators. They are not claimed to be the source workbook's restricted one-/two-qubit MUB experiment design. Inputs simulate independently fitted eigenvalue estimates under a declared Gaussian error model, not raw shots or new hardware data. The supplied identity eigenvalue record also has estimation noise, explicitly unlike the source's fixed trace-preservation row.

The reference reads only observations. `physical.py` independently evaluates Pauli commutation using unequal nonidentity symbols, without the binning/Walsh implementation. `build.py` checks sampled clean observations against that physical evaluator and stores fresh, unobserved spectra. Tests also exhaust all 64 Pauli errors on a three-qubit channel and all offset cosets. Thus planted truth verifies the reconstruction; it is not the reconstruction algorithm.
