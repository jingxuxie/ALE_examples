# Initial laboratory observations

The baseline runs all four supplied development cases. The two-hole device
shows a relative inductance reciprocity defect of approximately four percent,
although reported fluxoid-control residuals and linearity checks are very
small. Removing layer coupling changes the stacked device but leaves the
single-film controls unchanged. These observations should be reproduced, not
treated as target predictions for the repaired pipeline.

The planned readout points approach both sides of a current-carrying sheet.
A field calculation that agrees at a large lift-off need not be accurate there.
Compare independently meaningful quantities before interpreting apparent
agreement between two diagnostics that share the same approximations.

The scientific package and layout sources are provided under their original
license in `UPSTREAM_LICENSE`. The qualification adapter and frozen input
meshes are benchmark-authored. Upstream code is not intentionally corrupted;
the adapter's choices and the transfer in operating regime require qualification.
